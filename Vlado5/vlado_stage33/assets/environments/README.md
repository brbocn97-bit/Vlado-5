# assets/environments

Planned modular subsystem for Vlado Sipcic: The Last Outlaw (introduced in later development stages).

## CC0 Poly Haven environment resource

`hdris/autumn_field_2k.hdr` is a 2K outdoor HDR environment map downloaded from
Poly Haven for optional panoramic sky/reflection lighting. It is CC0 and documented
in `hdris/LICENSE.txt`.
